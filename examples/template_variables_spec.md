# DOCX 模板变量规范

> 定义 dify-json-to-docx-skill 的 DOCX 模板中可用的变量语法、数据类型和渲染规则。

---

## 1. 变量语法总览

本 Skill 使用基于 Jinja2 的模板语法（通过 docxtpl 实现），在 DOCX 模板的文本内容中嵌入占位符标记。所有标记均使用双花括号 `{{ }}` 包裹。

| 语法 | 类型 | 说明 |
|------|------|------|
| `{{field}}` | 变量替换 | 将占位符替换为 JSON 中对应字段的值 |
| `{{object.field}}` | 嵌套变量 | 访问嵌套对象中的子字段 |
| `{{#array}}` ... `{{/array}}` | 表格循环 | 为数组中的每个元素复制当前表格行 |
| `{{#if field}}` ... `{{/if}}` | 条件渲染 | 当字段为真值时显示内容块 |
| `{{%image_field}}` | 图片插入 | 在占位符位置插入图片 |
| `{{ field \| default('N/A') }}` | 默认值 | 字段为空时使用默认值 |
| `{{ field \| upper }}` | 过滤器 | 对值应用格式化过滤器 |

---

## 2. 变量替换

### 基本用法

在 Word 文档的任意文本位置插入 `{{字段名}}`，渲染时会被替换为 JSON 数据中同名字段的值。

**模板内容**：
```
客户名称：{{customer_name}}
结算日期：{{date}}
合同编号：{{contract_number}}
```

**JSON 数据**：
```json
{
  "customer_name": "示例科技有限公司",
  "date": "2026-08-12",
  "contract_number": "HT-2026-0042"
}
```

**渲染结果**：
```
客户名称：示例科技有限公司
结算日期：2026-08-12
合同编号：HT-2026-0042
```

### 嵌套对象

使用点号语法访问嵌套 JSON 对象的字段。

**模板内容**：
```
结算单编号：{{document_info.number}}
供应商：{{settlement.supplier_name}}
```

**JSON 数据**：
```json
{
  "document_info": { "number": "JS-2026-08-001" },
  "settlement": { "supplier_name": "云端智能服务有限公司" }
}
```

**渲染结果**：
```
结算单编号：JS-2026-08-001
供应商：云端智能服务有限公司
```

### 支持的数据类型

| JSON 类型 | 渲染行为 | 示例 |
|-----------|---------|------|
| String | 直接输出文本 | `"hello"` → `hello` |
| Number | 输出数字字符串 | `42` → `42` |
| Boolean | 输出 `true` / `false` | `true` → `true` |
| null | 输出空字符串（宽松模式）或报错（严格模式） | `null` → `` |
| Array | 不能直接输出，必须用循环语法 | — |
| Object | 不能直接输出，必须用点号语法访问子字段 | — |

## 3. 表格循环

### 基本用法

在 Word 表格中，将需要循环的行的单元格内放置 `{{#数组名}}` 和 `{{/数组名}}` 标记。渲染时，该行会被复制 N 次（N = 数组长度），每次用数组中的一个元素填充行内的变量。

**模板表格**：

| 序号 | 项目名称 | 规格 | 数量 | 单价 | 金额 |
|------|---------|------|------|------|------|
| {{item.index}} | {{item.name}} | {{item.spec}} | {{item.quantity}} | {{item.unit_price}} | {{item.amount}} |

> 在 Word 中实际操作时，`{{#items}}` 和 `{{/items}}` 标记需要放在循环行的单元格中。推荐做法：在第一个单元格中放 `{{item.index}}`，在最后一个单元格中放 `{{item.amount}}`，然后在任意单元格的末尾添加 `{{#items}}`，在另一个单元格中添加 `{{/items}}`。

**更清晰的模板写法**（docxtpl 推荐方式）：

| 序号 | 项目名称 | 规格 | 数量 | 单价 | 金额 |
|------|---------|------|------|------|------|
| {{%s}} {{item.index}} | {{item.name}} | {{item.spec}} | {{item.quantity}} | {{item.unit_price}} | {{item.amount}} |

其中 `{{%s}}` 是 docxtpl 的行标记语法，表示这一行是循环行。更常见的写法是直接在行中使用 `{{#items}}` 开始标记。

**实际推荐写法** — 将循环标记放在行内：

在 Word 表格的循环行中，任意单元格内放置以下内容：

```
{{#items}}{{item.index}}    {{item.name}}    {{item.spec}}    {{item.quantity}}    {{item.unit_price}}    {{item.amount}}{{/items}}
```

或者分散在单元格中（docxtpl 会自动识别）：

| {{item.index}} | {{item.name}} | {{item.spec}} | {{item.quantity}} | {{item.unit_price}} | {{item.amount}} |
| {{#items}} | | | | | {{/items}} |

**JSON 数据**：
```json
{
  "items": [
    {"index": 1, "name": "云服务器租赁费", "spec": "8核16G", "quantity": 1, "unit_price": "3200.00", "amount": "3200.00"},
    {"index": 2, "name": "对象存储服务费", "spec": "1TB", "quantity": 1, "unit_price": "850.00", "amount": "850.00"},
    {"index": 3, "name": "CDN流量费", "spec": "500GB", "quantity": 500, "unit_price": "0.24", "amount": "120.00"}
  ]
}
```

**渲染结果**：

| 序号 | 项目名称 | 规格 | 数量 | 单价 | 金额 |
|------|---------|------|------|------|------|
| 1 | 云服务器租赁费 | 8核16G | 1 | 3200.00 | 3200.00 |
| 2 | 对象存储服务费 | 1TB | 1 | 850.00 | 850.00 |
| 3 | CDN流量费 | 500GB | 500 | 0.24 | 120.00 |

### 嵌套循环

支持在循环内部再嵌套循环。例如每个项目下有多个子项：

```json
{
  "categories": [
    {
      "name": "硬件费用",
      "sub_items": [
        {"name": "服务器", "amount": "50000"},
        {"name": "交换机", "amount": "8000"}
      ]
    }
  ]
}
```

模板中使用 `{{#categories}}` 外层循环，内部使用 `{{#sub_items}}` 内层循环。

## 4. 条件渲染

### 基本用法

`{{#if field}}` ... `{{/if}}` 标记的内容块，仅在 `field` 为真值时显示。

**模板内容**：
```
{{#if has_tax}}
税率：{{tax_rate}}
税额：{{tax_amount}}
{{/if}}
合计：{{total}}
```

**JSON 数据（含税）**：
```json
{
  "has_tax": true,
  "tax_rate": "6%",
  "tax_amount": "388.20",
  "total": "6858.20"
}
```

**渲染结果**：
```
税率：6%
税额：388.20
合计：6858.20
```

**JSON 数据（不含税）**：
```json
{
  "has_tax": false,
  "tax_rate": "6%",
  "tax_amount": "388.20",
  "total": "6470.00"
}
```

**渲染结果**：
```
合计：6470.00
```

### 真值判断规则

| JSON 值 | 判定结果 |
|---------|---------|
| `true` | 真 |
| `false` | 假 |
| 非空字符串 | 真 |
| 空字符串 `""` | 假 |
| 非零数字 | 真 |
| `0` | 假 |
| `null` | 假 |
| 非空数组 | 真 |
| 空数组 `[]` | 假 |

## 5. 图片插入

### 基本用法

`{{%image_field}}` 语法在文档中插入图片。JSON 数据中对应字段的值为 Base64 编码的图片数据。

**模板内容**：
```
公司LOGO：{{%logo}}
```

**JSON 数据**：
```json
{
  "logo": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."
}
```

### 图片尺寸控制

通过模板中图片占位符的大小控制输出尺寸。在 Word 模板中插入一个图片，调整到期望的大小，然后将图片替换为 `{{%image_field}}` 标记。docxtpl 会保持该图片占位符的尺寸，替换为实际图片内容。

也可以使用内联语法指定尺寸：

```
{{%logo | size(200, 60)}}
```

其中 `200` 为宽度（像素），`60` 为高度（像素）。

### 支持的图片格式

- PNG（推荐）
- JPEG / JPG
- GIF
- BMP
- SVG（部分 Word 版本支持）

## 6. 过滤器

过滤器使用管道符 `|` 应用到变量上，对值进行格式化处理。

| 过滤器 | 说明 | 示例 |
|--------|------|------|
| `default('文本')` | 值为空时使用默认值 | `{{name \| default('未填写')}}` |
| `upper` | 转大写 | `{{code \| upper}}` |
| `lower` | 转小写 | `{{email \| lower}}` |
| `trim` | 去除首尾空格 | `{{name \| trim}}` |
| `length` | 数组长度 | `{{items \| length}}` |
| `replace('a','b')` | 字符串替换 | `{{text \| replace('旧','新')}}` |
| `round(2)` | 数字保留小数 | `{{price \| round(2)}}` |
| `thousands` | 千分位分隔 | `{{amount \| thousands}}` → `6,858.20` |

## 7. 模板制作指南

### 7.1 使用 Word / WPS 制作模板

1. 打开 Word 或 WPS，按照最终文档的样式设计排版（字体、字号、颜色、表格样式、页眉页脚等）。
2. 在需要插入数据的位置，输入对应的变量标记（如 `{{customer_name}}`）。
3. 对于表格循环行，在行内放置循环标记和变量。
4. 对于条件内容，用 `{{#if}}` ... `{{/if}}` 包裹。
5. 保存为 `.docx` 格式。

### 7.2 变量命名规范

- 使用小写字母 + 下划线：`customer_name`（推荐）
- 或使用小驼峰：`customerName`
- 不要使用空格或特殊字符
- 嵌套对象使用点号：`settlement.supplier_name`
- 数组元素在循环内使用相对路径：`item.name`（而非 `items[0].name`）

### 7.3 常见陷阱

**变量跨 Run 问题** — Word 在编辑过程中可能将一个变量名拆分到多个 XML Run 中（例如 `{{customer` 和 `_name}}` 分属不同的 Run）。docxtpl 通常能自动处理这种情况，但如果遇到变量未替换的问题，尝试在 Word 中删除变量文本后重新手动输入（不要复制粘贴）。

**表格循环行位置** — `{{#items}}` 和 `{{/items}}` 必须在同一个表格的同一行中。如果跨行或跨表格，渲染会失败。

**条件渲染与段落** — `{{#if}}` 和 `{{/if}}` 之间的内容如果包含多个段落，确保标记本身不会产生额外的空行。将标记放在段落的开头或末尾可以避免多余的空行。

**特殊字符转义** — 如果变量值中包含 `{{` 或 `}}`，会被误认为模板标记。确保 JSON 数据中的文本值不包含这些字符，或在服务端实现转义处理。
